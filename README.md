# ARMADA — a playable paper

A one-screen browser game about *Contesting the PRC's Fishing Armada* (J.R. Williamson, DARC, May 2025). You run Peru's response to a distant-water fishing fleet it can't board.

**Play:** https://lgs3.github.io/armada-play/

This repository holds only the built game, published from a private source repository.
